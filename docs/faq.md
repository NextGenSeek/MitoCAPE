# FAQ

## Which species are supported?

Currently:

- Human
- Mouse
- Fly

## Can I use my own FASTA?

Yes:

```bash
--fasta-path my_reference.fasta
````

## Can I use my own gene annotations?

Yes:

```bash
--gene-map-path my_genes.csv
```

## Why are no plots generated?

Check:

* input file format
* output permissions
* required dependencies

## What does MitoCAPE output?

* Processed annotated CSV
* Summary statistics
* Publication-ready figures
